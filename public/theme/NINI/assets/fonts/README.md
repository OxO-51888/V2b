# NINI interface font

Hanyi LeMiao (汉仪乐喵体 简) is used for all live text in the current local
preview: navigation, headings, buttons, labels, configured/user content, plan
names, prices, numbers, dates, notices and chat messages. Former in-image copy
is now a separate SVG text layer over clean illustration backgrounds. Existing
bold headings and labels retain bold weight; only weight synthesis is enabled
for this regular font. All content continues to follow its existing settings
and data sources.

User-supplied source: https://font.chinaz.com/220328236970.htm
Original archive: https://zf.sc.chinaz.com/Files/DownLoad/font/xmfont3281hgr.rar
The downloaded font is preserved without subsetting or modification. The source
provides it for reference and personal trial. No deployment was made as part of
this local font trial.
