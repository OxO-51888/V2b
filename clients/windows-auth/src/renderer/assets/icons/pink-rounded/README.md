# Pink Rounded Client Icons

Cute rounded 24px SVG icons for the desktop client UI.

## Files

- `start-agent.svg` - 启动代理
- `plan-purchase.svg` - 套餐购买
- `order-detail.svg` - 订单详情
- `logout.svg` - 退出登录
- `latency-test.svg` - 延迟测试
- `settings.svg` - 设置
- `minimize.svg` - 最小化
- `maximize.svg` - 最大化
- `close.svg` - 关闭

## Style

- Canvas: `24 x 24`
- Primary stroke: `#F0609A`
- Soft fill: `#FFE5F0`
- Accent fill: `#FFB3CF`
- Rounded caps and joins for a small, friendly client-interface look.
